FFmpeg license and source

FFmpeg 9.0.2, revision 2 · Published 26 November 2026

On a Mac without ffmpeg, YummyOrange downloads its own copy once, for audio and video. That copy is FFmpeg 9.0.2 under the GNU Lesser General Public License, version 2.1 or later, built with nothing under the GPL and nothing non-free. Everything it was made from, and how, is on this page, so you can check it or build it yourself.

What it is

  • One program. ffmpeg from FFmpeg 9.0.2, for Macs with Apple silicon and macOS 13 or later. It is a separate program that YummyOrange runs for audio and video work; YummyOrange itself contains none of its code.
  • When it’s downloaded. Once, from this website: about a minute after YummyOrange opens on a Mac without ffmpeg, on a network that isn’t metered (not Low Data Mode or a phone’s hotspot), or as soon as you start on a sound or video. Settings › About can download it at once, or cancel a download under way. After that, only when an update of YummyOrange comes with a new build of it. Before unpacking it, YummyOrange checks its exact size and SHA-256 against the values built into the app.
  • Where it goes. ~/Library/Application Support/YummyOrange/Helpers/ffmpeg-9.0.2-2, with its license file. Updates to YummyOrange leave it there, and Settings › About shows it as Installed by YummyOrange.
  • An ffmpeg you already have comes first. If your Mac has ffmpeg in /opt/homebrew/bin, /usr/local/bin or ~/.local/bin (from Homebrew, say), YummyOrange uses that one, under its own license, and downloads nothing. If that ffmpeg stops working, YummyOrange uses its own instead.
  • The download itself. YummyOrange-ffmpeg-9.0.2-2-arm64.zip, 11.5 MB, SHA-256 b8559d118c74ecab50855f92f1f6552af72f3119669a42653e04c7097dd927df.
  • What it leaves out. Anything that would make it a GPL build, such as the x264 encoder and FFmpeg’s boxblur filter (YummyOrange blurs with avgblur instead). It has no dav1d either, so AV1 video is read with the Mac’s own hardware decoder, which Macs with M3 or later have.

License

FFmpeg is free software under the GNU Lesser General Public License (LGPL), version 2.1 or (at your option) any later version. YummyOrange’s ffmpeg is configured without --enable-gpl, --enable-version3 and --enable-nonfree, so the program as a whole is under the LGPL 2.1 or later, and ffmpeg -L says the same. You may copy, change and pass it on under the terms of that license.

Most of FFmpeg is under the LGPL. LICENSE.md reproduces each of their notices with the files it comes from.

  • The GNU licenses on gnu.org: the GNU Lesser General Public License 2.1 and the GNU Library General Public License 2.
  • Each tarball below also holds its project’s own license files (COPYING, LICENSE, PATENTS).

Source code

The seven tarballs YummyOrange’s ffmpeg is built from, unchanged from each project’s own release. Their SHA-256 checksums are the same as Homebrew’s formulas for these versions. Build it yourself

build-ffmpeg-helper.sh rebuilds it from those tarballs on a Mac with Apple silicon and the Xcode Command Line Tools. It downloads nothing and installs nothing outside its own folder: it checks every checksum, runs the commands below, checks the program it made (arm64, macOS 13 or later, linked only to macOS’s own libraries, LGPL), writes LICENSE.md and BUILD.md and zips them. Built twice in different folders, it gave the same zip, byte for byte. BUILD.md is the record of this build that comes with it.

  1. Download the script and the seven tarballs into one folder.
  2. In Terminal, in that folder, run:
    SOURCES=. bash build-ffmpeg-helper.sh
  3. A few minutes later the folder holds YummyOrange-ffmpeg-9.0.2-2-arm64.zip. With the same tools as this build (Apple clang 21.0.0 and the macOS 27.2 SDK), shasum -a 256 prints the checksum above.

How it was built

Every library is built for arm64 and macOS 13.0 as a static library only, with this environment:

MACOSX_DEPLOYMENT_TARGET=13.0 ZERO_AR_DATE=1 CC=clang
CFLAGS="-arch arm64 -mmacosx-version-min=13.0 -O2 -g0"
LDFLAGS="-arch arm64 -mmacosx-version-min=13.0"

Each is installed with make install DESTDIR=<work>/prefix (prefix /usr/local inside that folder), so no path of the build Mac ends up in the program.

LAME 4.0

./configure --prefix=/usr/local --enable-static --disable-shared --disable-frontend --disable-decoder --disable-dependency-tracking

libogg 1.3.6

./configure --prefix=/usr/local --enable-static --disable-shared --disable-dependency-tracking

libvorbis 1.3.7

sed -i '' 's/ -force_cpusubtype_ALL//g' configure
./configure --prefix=/usr/local --enable-static --disable-shared --disable-docs --disable-examples --disable-oggtest --disable-dependency-tracking

Opus 1.6.1

./configure --prefix=/usr/local --enable-static --disable-shared --disable-doc --disable-extra-programs --disable-dependency-tracking

libwebp 1.6.0

./configure --prefix=/usr/local --enable-static --disable-shared --enable-libwebpmux --enable-libwebpdemux --disable-png --disable-jpeg --disable-tiff --disable-gif --disable-wic --disable-gl --disable-sdl --disable-dependency-tracking

libvpx 1.17.0

With CFLAGS and LDFLAGS empty; libvpx sets its own.

./configure --prefix=/usr/local --target=arm64-darwin22-gcc --extra-cflags=-mmacosx-version-min=13.0 --enable-static --disable-shared --enable-pic --enable-runtime-cpu-detect --disable-vp8 --disable-vp9-decoder --enable-vp9-encoder --disable-examples --disable-tools --disable-docs --disable-unit-tests --disable-debug-libs

FFmpeg 9.0.2

As ffmpeg -version prints it. The relative paths are from the unpacked source folder, which sits in <work>/build.

./configure --pkg-config=../../tools/pkg-config --pkg-config-flags=--static --cc=clang --arch=aarch64 --target-os=darwin --extra-cflags='-arch arm64 -mmacosx-version-min=13.0 -I../../prefix/usr/local/include' --extra-ldflags='-arch arm64 -mmacosx-version-min=13.0 -L../../prefix/usr/local/lib' --extra-libs=-liconv --extra-ldexeflags='-Wl,-dead_strip -Wl,-oso_prefix,.' --enable-static --disable-shared --disable-autodetect --enable-pthreads --enable-zlib --enable-bzlib --enable-iconv --enable-videotoolbox --enable-audiotoolbox --enable-libmp3lame --enable-libwebp --enable-libvpx --enable-libopus --enable-libvorbis --disable-network --disable-protocols --enable-protocol='file,pipe' --disable-devices --enable-indev=lavfi --enable-ffmpeg --disable-ffprobe --disable-ffplay --disable-doc --disable-debug

The program is then stripped and signed ad hoc (codesign -s - -f --options runtime), and zipped with its LICENSE.md and BUILD.md:

ditto -c -k --keepParent --norsrc --noextattr --noqtn --noacl ffmpeg-helper YummyOrange-ffmpeg-9.0.2-2-arm64.zip
