Edit PDF text on a Mac

YummyOrange’s Edit PDF changes a line of a PDF’s text in place, in the PDF’s own font, and adds new text. It is free, runs on your Mac with nothing uploaded, and saves the result as a new file, “name edited.pdf”, next to the original, which it never changes.

Download YummyOrange

Free and open source (MIT) · macOS 13 Ventura or later · Apple silicon · about 7 MB

How to edit a PDF on a Mac

  1. Open YummyOrange. It lives in the menu bar.
  2. Start dragging the PDF from Finder or the desktop, and press ⌘ Command. The Tools wheel opens under the pointer.
  3. Let go on Edit PDF…. A window opens with the page.
  4. Click a line and change its words, or add text where you need it.
  5. Save. “name edited.pdf” appears beside the original. It is saved as an incremental update, so the rest of the file stays exactly as it was.

More you can do with a PDF

  • Organize… pages: reorder, rotate, duplicate, delete and insert.
  • Merge two or more PDFs into one, or Split Pages into one PDF per page.
  • Compress, or Compress to… a size in MB for an email limit.
  • Add Password or Remove Password, make a PDF/A copy, Strip Metadata, Extract Text.
  • Convert it with ⇧ Shift: to Word (DOCX), TXT, Markdown, EPUB, PPTX, XLSX, PNG, JPG or SVG.

Questions

Is it really free?

Yes. YummyOrange is free and open source under the MIT licence. There’s no account, no watermark and no trial.

Is my PDF uploaded anywhere?

No. Editing happens on your Mac and the PDF never leaves it.

Can I edit a scanned PDF?

Edit PDF changes the text a PDF really contains. For a scan, Extract Text and the TXT and Markdown conversions read the page with text recognition (OCR).

Which Macs does it run on?

Macs with Apple silicon and macOS 13 Ventura or later.
